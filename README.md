# Приложение для получения данных о компаниях и вакансиях с сайта [hh.ru](https://hh.ru/)

### Перед использованием функционала выполните следующие действия:

1. Установите зависимости и пакеты из файла [pyproject.toml](pyproject.toml)
2. Переименуйте файл [database_yours.ini](database_yours.ini) в database.ini
3. В файле database.ini вместо **YOUR_PASSWORD** укажите свой пароль от базы данных Postgresql


## Работа в приложении:

1. Запустите файл [main.py](main.py)
2. Следуйте инструкциям
